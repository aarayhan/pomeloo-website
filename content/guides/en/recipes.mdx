Do the same three things to every photo? Make it a recipe.

<Demo name="recipe" />

## Make a recipe

<Steps>
  <Step title="Tray icon → Recipes… → New recipe">The recipe editor opens.</Step>
  <Step title="Give it a name">For example "Web photo".</Step>
  <Step title="Add steps">
    **Add a step…** offers every conversion and the tools with simple options (like Compress). Steps run top to
    bottom; set each one's options right there.
  </Step>
  <Step title="Save">The recipe appears as a ★ entry.</Step>
</Steps>

<Screenshot src="recipe-editor" alt="The recipe editor with two steps" />

## Run it

- Drag a file and tap <Keys k="Ctrl" />: your recipe is a **★** segment in the tools wheel.
- Right-click → Show more options → PomeloO → Tools → **★ Web photo**.
- Drag a file to the top of the screen: the notch shows a ★ zone too.

Recipes only show for files they can work on.

## Watch a folder

Turn on **Watch folder** in the recipe and choose a folder. From then on, every new file that lands there is run
through the recipe automatically, and the results go to its **Done** folder. Handy for a scanner's output folder,
or a folder your camera app syncs to.
