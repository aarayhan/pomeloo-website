The fastest way to do the usual things with a file: drag it to the top of the screen.

<Steps>
  <Step title="Drag a file from Explorer to the top edge of the screen">
    The notch opens into drop zones as soon as the file gets there.
  </Step>
  <Step title="Drop it on a zone">
    The top row converts to the usual formats for that file, or opens **Tools…** and **Actions…**. The bottom row
    has the shortcuts below.
  </Step>
</Steps>

<Screenshot src="notch-drop" alt="The notch's drop zones for a HEIC photo" caption="Drop zones for a photo." />

## The zones

| Zone | What it does |
|---|---|
| **JPG / PNG / PDF…** | Converts right away, saved next to the original |
| **Tools… / Actions…** | Opens that wheel for the file |
| **Shelf** | Keeps the file on the [notch's shelf](../notch/) |
| **Phone** | Shows the QR code to send it to your phone |
| **Fit WhatsApp** | Photos to about 1 MB; videos and PDFs under 16 MB |
| **Fit Email** | Under 25 MB, the usual attachment limit |
| **Fit Web** | WebP, at most 1920 px wide, around 300 KB |
| **★ your recipes** | Runs a [recipe](../recipes/) that fits this file type |

Only the zones that make sense for the file are shown: a PDF gets Fit WhatsApp and Fit Email, a photo gets all
three.

<Tip>
  The Fit zones pick the settings for you, so you don't have to know what "bitrate" means. The result is a new file;
  the original stays as it was.
</Tip>
