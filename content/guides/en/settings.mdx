Right-click the tray icon → **Settings…**. Press **Save** to apply.

<Screenshot src="settings" alt="The Settings window" />

## Wheel keys and keyboard

- **Wheel keys**: which tap opens Convert, Tools and Actions while dragging (Shift, Ctrl or Alt).
- **Wheel hotkey**: opens the wheel for the files selected in Explorer (or what you copied). Default
  <Keys k="Ctrl+Shift+Space" />.
- **Copy text from screen**: default <Keys k="Win+Ctrl+T" />.

Shortcuts apply after restarting PomeloO (tray → Quit, then start it from the Start menu).

## Behavior

| Setting | |
|---|---|
| **Start with Windows** | Opens PomeloO automatically after you sign in |
| **Update automatically** | Checks GitHub once a day and installs new versions by itself, while you're not using the PC |
| **Wheel while dragging** | Tap a key mid-drag to open the wheel |
| **Paste images as files** | Ctrl+V in a folder saves a copied picture there |
| **Floating drop pad** | A small target in the corner to drop files on |
| **Highlight sound** | A soft click as you move across the wheel |
| **Fix WhatsApp desktop clicks** | WhatsApp Desktop can leave an invisible layer that blocks right-clicks on the desktop; this clears it |

## Notch

Show or hide the notch; its **size** (Small makes the pill and the notices smaller), **position** (left, centre, right) and **screen** (main, or the one with the cursor);
progress in the notch instead of a floating window; ideas for new downloads and copied images; and which tabs to
show (Clipboard, Recent, Phone).
