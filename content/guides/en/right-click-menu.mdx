Not a fan of drag-and-tap? Every conversion, tool and action is also in Explorer's right-click menu.

<Steps>
  <Step title="Right-click a file (or several)">In Explorer or on the desktop.</Step>
  <Step title="Choose Show more options">
    Windows 11 hides older menus there. Shortcut: <Keys k="Shift" /> + right-click opens it straight away.
  </Step>
  <Step title="Point at PomeloO">
    Pick **Convert to**, **Tools** or **Actions**, then the item you want.
  </Step>
</Steps>

The menu shows the same choices as the wheel for that file type, including your ★ [recipes](../recipes/).

## Turning it on or off

The installer adds the menu when the **right-click menu** box is ticked. You can change your mind any time
from the tray icon:

- **Add to Explorer menu**
- **Remove from Explorer menu**

The menu is registered for your user only and is removed when you uninstall PomeloO.

<Note>
  Using the portable zip? Run `PomeloO.exe`, then tray menu → **Add to Explorer menu**. If you move the folder
  later, add it again so the menu points to the new place.
</Note>
