Notch adalah pil hitam kecil di bagian atas tengah layar. Ia tidak mengganggu sampai kamu membutuhkannya.

<Screenshot src="notch-pill-shelf" alt="Notch sebagai pil kecil" caption="Saat diam: hanya sebuah pil. Ia memberi tahu berapa file yang ada di rak." />

<Demo name="notch" />

## Membuka panel

Arahkan kursor ke pil sebentar, atau klik. Panel turun dengan lima tab dan tombol **Copy text from screen**.
Jauhkan mouse dan panel akan terlipat lagi.

### Shelf (rak)

<Screenshot src="notch-shelf" alt="Tab Shelf berisi empat file" />

Tempat menaruh file sementara selagi bekerja: jatuhkan file ke panel supaya selalu dekat. File tetap ada di rak
walaupun PC di-restart.

- **Seret file keluar** ke aplikasi, folder atau chat mana pun untuk memakainya di sana.
- **Shift+seret** file keluar untuk menjatuhkannya dalam bentuk sudah dikonversi: PNG → JPG, DOCX → PDF, MKV → MP4…
- **Arahkan kursor** ke file untuk melihat pratinjau.
- **Clear** mengosongkan rak (file aslinya tidak disentuh).

### Jobs

<Screenshot src="notch-jobs" alt="Tab Jobs dengan kompresi yang sedang berjalan" />

Setiap konversi dan alat menampilkan progresnya di sini, dengan tombol **Cancel**. Setelah selesai, terlihat
berapa ruang yang dihemat dan tombol **Show** yang memilih hasilnya di Explorer.

### Clipboard

<Screenshot src="notch-clipboard" alt="Tab Clipboard" />

Enam hal terakhir yang kamu salin (teks dan gambar), siap disalin lagi atau diseret keluar. Hanya ada di memori,
tidak pernah disimpan ke disk, dan melewati apa pun yang ditandai privat oleh password manager.

### Recent

<Screenshot src="notch-recent" alt="Tab Recent" />

Hasil-hasil terbaru, siap diseret keluar, masing-masing dengan **Undo**.

### Phone

Kode QR untuk mengirim file ke HP dan menerima file darinya, langsung di notch. Lihat
[Kirim dan terima lewat HP](../phone/).

## Pemberitahuan dan ide

Pesan selesai, ruang yang dihemat dan file yang datang dari HP muncul di notch, bukan sebagai balon Windows.

<Screenshot src="notch-toast" alt="Pemberitahuan selesai di notch" />

Saat ada file baru di Downloads, notch menyarankan langkah berikutnya, misalnya **→ JPG** untuk foto HEIC.
Screenshot yang disalin bisa disimpan sebagai file, dibaca (OCR), dicoret atau dikirim ke HP dengan sekali klik.

<Screenshot src="notch-suggest" alt="Ide untuk file yang baru diunduh" />

## Tahu kapan harus sembunyi

- Ia menyingkir saat ada aplikasi layar penuh, game, dan presentasi.
- Ia tidak pernah muncul di screenshot atau saat berbagi layar.
- Saat battery saver menyala, animasinya dilewati.

Ubah posisinya (kiri, tengah, kanan), layarnya, dan tab mana yang ditampilkan di Settings → **Notch**.
Berikutnya: [jatuhkan file ke notch](../notch-drop/).
