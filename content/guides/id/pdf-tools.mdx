Seret PDF lalu ketuk <Keys k="Ctrl" />. Untuk mengubah PDF ke Word, PowerPoint, Excel, gambar atau EPUB, ketuk
<Keys k="Shift" />.

<Screenshot src="wheel-tools-pdf" alt="Roda tools untuk sebuah PDF" />

## Merge PDFs (gabung)

<Steps>
  <Step title="Pilih semua PDF-nya">Ctrl+klik di Explorer.</Step>
  <Step title="Seret bersamaan lalu ketuk Ctrl">Pilih **Merge PDFs**.</Step>
  <Step title="Atur urutannya, lalu Merge">Satu PDF gabungan disimpan di sebelah file pertama.</Step>
</Steps>

## Organize PDF

<Screenshot src="tool-organizePDF" alt="Jendela Organize PDF dengan thumbnail halaman" />

Atur urutan, putar, gandakan dan hapus halaman, dengan thumbnail. **Split PDF** membagi satu PDF jadi beberapa file.

## Password

<Screenshot src="tool-protectPDF" alt="Jendela Add Password" />

**Add Password** mengunci PDF dengan AES-256. **Remove Password** membuat salinan tanpa kunci (perlu password yang
sekarang). Password tidak pernah disimpan, bahkan di History.

## Watermark dan nomor halaman

<Screenshot src="tool-watermarkPDF" alt="Jendela Add Watermark" />

**Add Watermark**: teks, ukuran, transparansi, sudut dan warna pilihanmu di setiap halaman.

<Screenshot src="tool-numberPDF" alt="Jendela Page Numbers" />

**Page Numbers**: "1", "Page 1", "1 / 10" atau "Page 1 of 10", di salah satu dari enam posisi, mulai dari angka berapa
saja.

## Hasil scan

- **Searchable PDF** menambahkan lapisan teks tak terlihat ke halaman hasil scan, jadi bisa dicari dan disalin.
- **Copy Text (OCR)** menaruh teks seluruh PDF ke clipboard.
- **Compress** membuat PDF besar (biasanya penuh foto) jadi jauh lebih kecil.
