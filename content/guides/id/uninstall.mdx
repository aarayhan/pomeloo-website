## Update

PomeloO memperbarui dirinya sendiri. Sekali sehari ia mengecek GitHub; kalau ada versi baru, ia mengunduhnya, mencocokkan
SHA-256-nya, lalu memasangnya saat PC sedang tidak kamu pakai (tidak ada proses berjalan, tidak ada jendela terbuka),
kemudian terbuka lagi dan memberi tahu di notch. Pengaturan, resep dan riwayatmu tetap ada. Lihat [yang baru](../../changelog/).

- Untuk update sekarang juga: ikon tray → **Check for updates…**
- Untuk mematikannya: Settings → **Update automatically**. Setelah itu, update dengan mengunduh installer terbaru dari
  [halaman unduh](../../download/) lalu menjalankannya.
- Zip portabel tidak memperbarui dirinya sendiri; PomeloO memberi tahu kalau ada versi baru.

## Uninstall

<Steps>
  <Step title="Buka Settings Windows → Apps → Installed apps">Atau cari "Add or remove programs".</Step>
  <Step title="Temukan PomeloO → ⋯ → Uninstall">Aplikasinya ditutup dulu.</Step>
</Steps>

Ini juga menghapus menu klik kanan, entri mulai bersama Windows dan salinan pribadi LibreOffice (kalau pernah diunduh).
Pengaturanmu di `%APPDATA%\PomeloO` tetap disimpan, siapa tahu kamu kembali; hapus folder itu untuk menghapusnya juga.

<Note>
  Pakai zip portabel? Tray → **Remove from Explorer menu**, matikan **Start with Windows** di Settings, keluar, lalu
  hapus foldernya.
</Note>
