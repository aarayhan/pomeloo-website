Cara tercepat melakukan hal-hal yang biasa dengan sebuah file: seret ke bagian atas layar.

<Steps>
  <Step title="Seret file dari Explorer ke tepi atas layar">
    Notch langsung berubah menjadi zona-zona jatuhan begitu file-nya sampai di sana.
  </Step>
  <Step title="Lepaskan di salah satu zona">
    Baris atas mengonversi ke format yang umum untuk file itu, atau membuka **Tools…** dan **Actions…**. Baris
    bawah berisi jalan pintas di bawah ini.
  </Step>
</Steps>

<Screenshot src="notch-drop" alt="Zona jatuhan notch untuk foto HEIC" caption="Zona jatuhan untuk sebuah foto." />

## Zona-zonanya

| Zona | Fungsinya |
|---|---|
| **JPG / PNG / PDF…** | Langsung mengonversi, disimpan di sebelah file asli |
| **Tools… / Actions…** | Membuka roda itu untuk file tersebut |
| **Shelf** | Menyimpan file di [rak notch](../notch/) |
| **Phone** | Menampilkan kode QR untuk mengirimnya ke HP |
| **Fit WhatsApp** | Foto jadi sekitar 1 MB; video dan PDF di bawah 16 MB |
| **Fit Email** | Di bawah 25 MB, batas lampiran yang umum |
| **Fit Web** | WebP, lebar maksimal 1920 px, sekitar 300 KB |
| **★ resep kamu** | Menjalankan [resep](../recipes/) yang cocok untuk jenis file ini |

Hanya zona yang masuk akal untuk file itu yang ditampilkan: PDF mendapat Fit WhatsApp dan Fit Email, foto
mendapat ketiganya.

<Tip>
  Zona Fit memilihkan pengaturannya untukmu, jadi kamu tidak perlu tahu apa itu "bitrate". Hasilnya file baru;
  file aslinya tetap seperti semula.
</Tip>
