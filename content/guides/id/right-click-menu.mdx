Kurang suka seret-lalu-ketuk? Semua konversi, alat dan aksi juga ada di menu klik kanan Explorer.

<Steps>
  <Step title="Klik kanan sebuah file (atau beberapa)">Di Explorer atau di desktop.</Step>
  <Step title="Pilih Show more options">
    Windows 11 menyembunyikan menu lama di sana. Jalan pintas: <Keys k="Shift" /> + klik kanan langsung membukanya.
  </Step>
  <Step title="Arahkan ke PomeloO">
    Pilih **Convert to**, **Tools** atau **Actions**, lalu item yang kamu mau.
  </Step>
</Steps>

Menunya menampilkan pilihan yang sama dengan roda untuk jenis file itu, termasuk ★ [resep](../recipes/) kamu.

## Menyalakan atau mematikannya

Installer menambahkan menu ini kalau kotak **right-click menu** dicentang. Kamu bisa berubah pikiran kapan saja
lewat ikon tray:

- **Add to Explorer menu**
- **Remove from Explorer menu**

Menu ini hanya terdaftar untuk akun kamu dan ikut terhapus saat PomeloO di-uninstall.

<Note>
  Pakai zip portabel? Jalankan `PomeloO.exe`, lalu menu tray → **Add to Explorer menu**. Kalau foldernya kamu
  pindahkan nanti, tambahkan lagi supaya menunya menunjuk ke lokasi baru.
</Note>
