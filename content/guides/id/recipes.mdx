Selalu melakukan tiga hal yang sama pada setiap foto? Jadikan resep.

<Demo name="recipe" />

## Membuat resep

<Steps>
  <Step title="Ikon tray → Recipes… → New recipe">Editor resep terbuka.</Step>
  <Step title="Beri nama">Misalnya "Web photo".</Step>
  <Step title="Tambahkan langkah">
    **Add a step…** menawarkan semua konversi dan alat yang pilihannya sederhana (seperti Compress). Langkah dijalankan
    dari atas ke bawah; atur pilihan tiap langkah langsung di sana.
  </Step>
  <Step title="Save">Resepnya muncul sebagai entri ★.</Step>
</Steps>

<Screenshot src="recipe-editor" alt="Editor resep dengan dua langkah" />

## Menjalankannya

- Seret file lalu ketuk <Keys k="Ctrl" />: resepmu jadi segmen **★** di roda tools.
- Klik kanan → Show more options → PomeloO → Tools → **★ Web photo**.
- Seret file ke atas layar: notch juga menampilkan zona ★.

Resep hanya muncul untuk file yang bisa diprosesnya.

## Memantau folder

Nyalakan **Watch folder** di resep lalu pilih sebuah folder. Sejak itu, setiap file baru yang masuk ke sana otomatis
diproses dengan resep tersebut, dan hasilnya masuk ke folder **Done**-nya. Berguna untuk folder hasil scanner, atau
folder yang disinkronkan aplikasi kamera.
