Klik kanan ikon tray → **Settings…**. Tekan **Save** untuk menerapkan.

<Screenshot src="settings" alt="Jendela Settings" />

## Wheel keys dan keyboard

- **Wheel keys**: ketukan mana yang membuka Convert, Tools dan Actions saat menyeret (Shift, Ctrl atau Alt).
- **Wheel hotkey**: membuka roda untuk file yang dipilih di Explorer (atau yang kamu salin). Bawaannya
  <Keys k="Ctrl+Shift+Space" />.
- **Copy text from screen**: bawaannya <Keys k="Win+Ctrl+T" />.

Shortcut berlaku setelah PomeloO dijalankan ulang (tray → Quit, lalu buka lagi dari menu Start).

## Behavior

| Pengaturan | |
|---|---|
| **Start with Windows** | Membuka PomeloO otomatis setelah kamu masuk ke Windows |
| **Update automatically** | Mengecek GitHub sekali sehari dan memasang versi baru sendiri, saat PC sedang tidak kamu pakai |
| **Wheel while dragging** | Ketuk tombol saat menyeret untuk membuka roda |
| **Paste images as files** | Ctrl+V di folder menyimpan gambar yang disalin ke sana |
| **Floating drop pad** | Target kecil di pojok layar untuk menjatuhkan file |
| **Highlight sound** | Bunyi klik halus saat kursor melewati roda |
| **Fix WhatsApp desktop clicks** | WhatsApp Desktop kadang meninggalkan lapisan tak terlihat yang menghalangi klik kanan di desktop; ini membersihkannya |

## Notch

Tampilkan atau sembunyikan notch; **ukurannya** (Small membuat pill dan notifikasi lebih kecil), **posisinya** (kiri, tengah, kanan) dan **layarnya** (utama, atau layar tempat
kursor berada); progres di notch alih-alih jendela mengambang; ide untuk unduhan baru dan gambar yang disalin; serta tab
mana yang ditampilkan (Clipboard, Recent, Phone).

## Exhibition mode

Mau memamerkan PomeloO di booth atau di kelas? Ikon tray → **Exhibition mode**. Selama aktif:

- Tombol yang kamu tekan muncul besar di atas taskbar (**Shift**, **Win + Ctrl + T**), jadi orang yang menonton
  tahu apa yang kamu lakukan. Ketikan biasa tidak pernah ditampilkan.
- Setelah 45 detik PC tidak disentuh, muncul kartu yang mengajak pengunjung mencoba tiga hal, lengkap dengan QR
  ke website ini.
- Notifikasi "Copied" tampil besar di tengah layar.
- PomeloO tidak memasang update, jadi tidak akan restart di tengah demo.

Tray → **Reset demo folder** mengisi **Desktop\PomeloO Demo** dengan file contoh baru (foto HEIC, video, lagu, PDF,
poster ber-QR) lalu membukanya. Tekan lagi di antara pengunjung untuk membersihkan hasil mereka.
