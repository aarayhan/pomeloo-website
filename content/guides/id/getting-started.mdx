PomeloO adalah aplikasi kecil yang tinggal di system tray. Tidak ada jendela utama yang perlu dibuka: kamu
memakainya langsung dari Explorer, sambil menyeret file.

## Memasang

<Steps>
  <Step title="Unduh installer-nya">
    Ambil **PomeloO-Setup-x.y.z.exe** dari [halaman unduh](../../download/). Butuh Windows 10 (1809 atau lebih
    baru) atau Windows 11, 64-bit.
  </Step>
  <Step title="Jalankan">
    Tidak perlu hak admin. PomeloO terpasang hanya untuk akun kamu, menambah entri di menu Start dan, kalau
    kotaknya tetap dicentang, menu klik kanan di Explorer.
  </Step>
  <Step title="Muncul &ldquo;Windows protected your PC&rdquo;? Klik More info → Run anyway">
    Installer-nya belum ditandatangani, jadi SmartScreen belum mengenalnya. Kode sumber dan proses build-nya
    terbuka di GitHub.
  </Step>
  <Step title="Cari ikon oranye di tray">
    PomeloO langsung berjalan, dan mulai sekarang ikut menyala bersama Windows. Klik panah **^** di sebelah jam
    kalau ikonnya tidak kelihatan.
  </Step>
</Steps>

<Note>
  Saat pertama jalan, PomeloO memampatkan foldernya sendiri dengan kompresi file bawaan Windows (sekitar 690 MB
  → 240 MB di disk). Ini berjalan diam-diam di latar belakang, dua menit setelah dibuka.
</Note>

## Konversi pertamamu

<Demo name="wheel" />

<Steps>
  <Step title="Buka folder yang berisi foto">Misalnya folder Pictures atau Downloads.</Step>
  <Step title="Mulai seret fotonya">Tekan dan tahan tombol kiri mouse di atas foto, lalu gerakkan sedikit.</Step>
  <Step title="Ketuk Shift selagi tombol mouse masih ditahan">Roda format muncul di bawah kursor.</Step>
  <Step title="Arahkan ke sebuah format lalu lepaskan">
    Salinan hasil konversi muncul di sebelah file asli, dengan nama seperti `photo.png`. File aslinya tidak
    pernah diubah.
  </Step>
</Steps>

<Tip>
  Berubah pikiran? Lepaskan di mana saja di luar roda, atau tekan <Keys k="Esc" />. Tidak ada yang terjadi pada
  file-nya.
</Tip>

## Ikon di tray

Klik kanan ikon oranye untuk **Receive from phone**, **Recipes**, **History** dan **Settings**. Semua yang
dilakukan PomeloO bisa diatur di Settings: tombol, shortcut, notch, dan lainnya.

Berikutnya: pelajari semua cara membuka [roda](../wheel/).
