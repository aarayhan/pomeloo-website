Ikon tray → **History…** menampilkan pekerjaan terakhir, dari yang terbaru.

<Screenshot src="history" alt="Jendela History dengan tombol Show, Undo dan Again" />

| Tombol | Fungsinya |
|---|---|
| **Show** | Memilih hasilnya di Explorer |
| **Undo** | Memindahkan hasilnya ke Recycle Bin; penggantian nama dikembalikan |
| **Again** | Menjalankan pekerjaan yang sama pada file yang sama, dengan pengaturan yang sama |

Tab **Recent** di notch juga berisi hasil terbaru dengan Undo, cukup dengan mengarahkan kursor.

<Note>
  Undo tidak pernah menghapus file aslimu: PomeloO memang tidak pernah mengubahnya. Password (dari Add Password) tidak
  pernah disimpan di History.
</Note>
